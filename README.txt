Problemas practicos - Parcial#2 programación estructurada

ARCHIVOS
- index.html: estructura de la página y campos de cada ejercicio.
- css/estilos.css: diseño visual, colores, márgenes y adaptación a móviles.
- js/script.js: validaciones y cálculos de los cuatro ejercicios.

CÓMO EJECUTAR
1. Extraiga el archivo ZIP en una carpeta.
2. Abra la carpeta en Visual Studio Code.
3. Abra index.html en un navegador. También puede usar la extensión Live Server.
4. Ingrese valores y pulse el botón del ejercicio correspondiente.
