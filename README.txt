PAR VS - Práctica de programación estructurada

ARCHIVOS
- index.html: estructura de la página y campos de cada ejercicio.
- css/estilos.css: diseño visual, colores, márgenes y adaptación a móviles.
- js/script.js: validaciones y cálculos de los cuatro ejercicios.
- capturas/: capturas ilustrativas de la interfaz para el documento.

CÓMO EJECUTAR
1. Extraiga el archivo ZIP en una carpeta.
2. Abra la carpeta en Visual Studio Code.
3. Abra index.html en un navegador. También puede usar la extensión Live Server.
4. Ingrese valores y pulse el botón del ejercicio correspondiente.

NOTA SOBRE EL DOCUMENTO
Abra PAR_VS_Informe.docx y complete los datos de estudiante, cédula, asignatura, docente y fecha.
Las imágenes incluidas en el documento son vistas ilustrativas de la interfaz. Para cumplir literalmente con
la indicación de capturas de cada archivo en ejecución, abra el proyecto en su equipo y reemplace o complemente
las imágenes con capturas propias del navegador y del código ejecutándose en Visual Studio Code.
